# @namzu/desktop

## 0.5.0

### Minor Changes

- 1c2f8fc: The conversation screen's message box is quieter. The box now holds only your text, the "+" for attachments and the send button (Stop and the queue button appear there while a reply runs), with rounder 16 px corners. The settings of the conversation moved to one small row under the box: the project and where it runs (home screen only), the permission mode ("Ask first" and the others, same menu), the model (it stays there, greyed out, while an approval waits) and the context percentage. The context percentage used to sit in the top bar; it now sits at the right end of that row, with the same popup and the same numbers. A narrow window drops the percentage first, then shortens the model's name, then wraps the row to two lines; the permission mode is never cut. An approval is now one card directly above the box instead of a box inside a box, with the preview of the change running edge to edge. On the home screen the project line fades out on your first message and the permission mode slides into place. Nothing you could do is gone: every control is still there, with the same words, menus and keys, and every one is drawn at rest, so the keyboard and touch reach it without hovering.
- 1c2f8fc: The window looks flatter. The list of conversations and the conversation are two plain regions with one thin line between them: the sidebar no longer has rounded corners or a set-in look, and nothing in the frame casts a shadow. The strip of icons on the left now appears only while the sidebar is closed. While the sidebar is open, Settings (and the update button, when there is an update to install) sit in a row at the bottom of the sidebar, with the same names, tooltips and shortcut as before; the Settings and Plugins pages also keep a Home button there. Opening or closing the sidebar moves the conversation by the width that changes and no more, and the sidebar's header now ends on the same line as the top bar. Nothing you could do before is gone: each button is where it always was while the sidebar is closed, and in the sidebar's foot while it is open. Home from a conversation is the sidebar's New conversation row.
- 1c2f8fc: The conversation screen is quieter after a turn. The result line under a finished reply is now one line of text with no box: it takes a soft fill only when you point at it or tab to it, and its "..." menu shows on hover, on focus or when open (always on a touch screen). A failing check keeps its red dot and red words. The line over the work now says what was done ("Read 2 files, created a file, and 2 more · 36s") instead of "Worked for 36s, 7 steps", and has no rule under it until opened. Your own message has slightly tighter corners and can be a little wider, and inline code no longer has an outline. Nothing you could do is gone: the line still opens the changes, and Undo, Open file and Copy summary are still in the "...".

### Patch Changes

- 5c5a3d8: In a second Desktop window, right-clicking a conversation that window had not opened showed no "Mark as unread", and Fork and Copy gave the wrong answer, because the menu looked at a thread that window never loaded. Main now keeps whether a conversation has a reply on its entry in the list, read from the saved log so it survives a restart, and every window follows it. A conversation with a reply offers Mark as unread in any window; Fork, New side chat, Copy as Markdown and Copy last reply say "Open the conversation first." until that window holds the conversation. A conversation with no reply is still not offered Mark as unread. The host's conversation list gains an optional `replied` field.

## 0.4.0

### Minor Changes

- 3a5f681: An approval is now one card instead of three boxes. The question is one sentence with the file or command as a chip and the size of the change at the right ("Edit `src/auth/session.ts`?", "+1 −1"). What the request itself says about the consequence comes first, with a warning mark: that Namzu asks about it every time, that the path is outside the project folder, a delete, a replaced file, elevated rights, a command that looks like it deletes. Nothing the model wrote about its own action is shown. The change or command is four rows with a link that says how much more there is ("Show all 24 lines") and opens it in place.

  **Accept is no longer held until a long command or diff has been scrolled to its end**; it works at once. The 400 ms guard after a card appears, Reject-first keys on risky commands and deletes, and the withheld "allow for this conversation" are unchanged. Enter still accepts and Esc still rejects; the keys now read on the buttons' tooltips instead of in a line of text. "Wrap lines", "Copy" and "Tell Namzu what to do instead" moved to a "..." menu on the box. "Allow for this conversation" is an outline button.

  While a decision waits, the composer is a 40 px bar saying so, with an outlined Stop that turns red on hover; the model word, context ring and microphone come back once you answer. The turn in flight is one line (a mark, the step it is on, the time, a chevron) with its actions behind the chevron; a failed or refused action keeps the work open.

  Long changed lines wrap on the card, so the end of a line is never hidden. A path that starts in the project folder and climbs out of it (`/project/../x`) is flagged as outside it, and every command in a request is checked for the elevated-rights and delete flags.

- 9c415f2: A finished turn now ends in one row that says how it went: "Done in 3s", how many files changed and by how much ("4 files +35 −3"), and what the turn's record says about checking, such as "Checked: pnpm test passed". A check that failed shows in red and cannot be missed, stays on the row when the reply is partly undone (with "Partly undone, 1 file kept" beside it), and the row then reads "Finished in 3s" rather than "Done in 3s"; a turn that was not checked shows only the counts. When a command ran that may have changed other files, the row still shows only the counts of the edits made with the edit tools, and the row's tooltip, its accessible name and Copy summary say so. Click the row to open the changes. It replaces the "Changed 4 files" card and the sentence under it: Undo, Open file and Copy summary are in the "..." at the end of the row, and "View changes" is the row itself. The menu lists the largest changes first, and after a full undo no longer offers the files that reply made. The fold above an answer now reads "Worked for 3s, 4 steps".

  The Changes pane opens wider (520 px, at most half of a small window) on the file that changed most, with a narrow list of files beside the diff instead of above it; a long file name is cut at its start so its end stays readable. Its header is one row: the title, a switch between This reply and All changes (All changes first), the counts, a View menu (split or unified, wrap lines, collapse folders, uncommitted changes, copy paths, expand) and close. The Activity tab is no longer drawn above Changes: open it from Conversation details, then Background work. The top bar's changes button shows the lines added and removed. In a window narrower than 1281 px the sidebar folds to its rail while the pane is open and comes back when you close it, unless you opened or closed it yourself in between.

SDK: `QueryParams.outsideRootRefusal` lets a host choose the sentence the model reads when `outsideRootAccess` is `'refuse'`; without it nothing changes.
