Desktop now shows what a turn made. A new Outputs tab in the side panel lists the files the conversation wrote and previews the one you pick: a web page in a locked frame (no scripts, no network, no way to leave the frame), a document as formatted text, code with line numbers and a copy button, an image as itself, with "Open in browser" and "Show in folder". It opens by itself when a turn writes or edits a page or a document. The host reads a file for the pane only if it is in the conversation's folder or one the conversation wrote. A turn that only ran a command, or was not checked, no longer ends with "A command ran that may have changed files · cannot tell" or "not checked"; a failing check and the "2 files +30 −4" line still show. While a turn runs, the status line names the step with its own seconds ("Running command 12s · 1m 4s"), says "Waiting for you" during an approval without counting that wait in the time, and keeps the last two steps in view. The model's name for a conversation (a short title in the conversation's language) now replaces the first words of the message in the sidebar and the header.
