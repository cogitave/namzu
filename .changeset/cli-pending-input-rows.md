Messages you type while Namzu is working now wait as grey `❯` rows above the input box instead of inside it; a Tab-queued one says `after this reply`. Press Up on an empty input to choose a queued message and Enter to edit it, or `ctrl+x ctrl+s` to send waiting messages now. Nothing changes in how messages reach the model.

They sit directly above the `Working` row, as in Claude Code.
