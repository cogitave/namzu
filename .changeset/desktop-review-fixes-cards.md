Cards under a reply are steadier. Files made by a command are found by the time they were written, and a turn in a very large folder shows none rather than a partial or wrong list. Older Word, Excel, PowerPoint and rich-text files stay cards you can save a copy of, but no longer open with the system's program. A stop that fails and a voice download that fails say what happened in plain words. A card no longer shows the file path on hover, and its picture carries the file type.
