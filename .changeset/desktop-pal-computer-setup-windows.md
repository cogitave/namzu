On Windows, Pal computers now run on Windows' own Linux container support and Namzu Desktop sets the PC up from the Pal computer row. Nothing changes for you if you already set `NAMZU_PAL_COMPUTER_ENGINE`; off Windows nothing changes at all. The row shows "Needs setup", then one sentence about what Windows will add and ask, then one progress label at a time; a restart is offered as "Restart now" and setup continues by itself after you sign in again. The Linux machine stops after 10 idle minutes.
