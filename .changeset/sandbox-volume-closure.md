Add read-only discovery and conditional opening of an existing Kubernetes workspace volume for a host-owned closure. Persist the observed Sandbox/PVC identity and exclude ordinary work before opening; unchanged epochs open running owners, while one epoch advance wakes only the captured suspended owner. The operation never creates resources or retries a failed patch. Authenticated session inventories include the agent boot identity; rebuild the guest image to use the new opener. Older images without that evidence refuse without deleting or replacing the disk.
