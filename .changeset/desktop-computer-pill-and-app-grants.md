Computer use in Desktop asks once per application ("Allow Namzu to use Notepad in this conversation?": Allow, Allow once, Deny) instead of on every click, and actions that close, delete, send or submit still ask. A small always-on-top pill shows which application Namzu is using and the last step, has Stop, and answers the questions itself, so the application being driven no longer hides them; each computer call shows a small picture of what the model saw with the click point; a covered Namzu window is brought forward once for a question in a turn that used the computer. The conversation's details list the applications used and let you take one back.
