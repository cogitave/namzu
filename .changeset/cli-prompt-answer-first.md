Shorter requests and fewer detours. The language rule (reply in the language of the person's latest message, give money when money is asked) is now the first sentence of the system prompt and appears once; the announce-before-acting line is gone from the identity and replaced by one narration rule for long work, so a plain question is answered without a line about what comes next. The main system message is about 4,000 characters shorter, and an explore agent's about 11,000 shorter: an `explore` or `plan` agent receives the working rules once under a read-only blurb, where it used to receive them twice with a worker blurb after the read-only one.
