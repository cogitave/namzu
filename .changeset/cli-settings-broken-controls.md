'@namzu/cli': patch

Several settings now do what their row says. `tui.mouse: off` (and `NAMZU_DISABLE_MOUSE`) asks the terminal for no pointer reports at all, so the terminal keeps its own wheel and selection in full screen; before, it behaved like `scroll`. `compaction.modelSummary` and `smallModel` now reach the automatic summary, so with a small model set the summary is written by it (before, only the manual compact used it). Desktop's settings writes refuse `model: auto` without `routing.default` in plain words instead of leaving a file the terminal app cannot load, keep a plain `learningGenerator: true|false` when a token number is saved beside it, clear `telemetry.sessionExport.destination` by removing the whole block, and check the trace address as an http or https address with no password. Ranges now match the loader (`workflow.maxConcurrency` 1 to 16, `schedule.maxConcurrentRuns` up to 16, learning tokens up to 10000000, `limits.timeoutMs` up to 2147483647, `limits.waitForProviderMs` at least 1). The plugin-folders description is gone, because the loader never read it from a file; use `--plugin-dir`. Settings descriptions say the real effect (turns, not tasks; the cache lifetime idle shortening needs; the memory curation writer that merging notes turns off). Saved values and key names are unchanged.
