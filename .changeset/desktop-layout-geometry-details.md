Details on a failed reply start closed for each new failure instead of staying open from the last one. A conversation's notice (for example "That folder no longer exists. Choose another folder.") takes its own row and no longer covers the first row of the transcript. Side-by-side panes that no longer fit the window are stacked instead of pushing the page sideways, and "New terminal to the right" in a narrow window opens the terminal below; a split that does not fit says the window is too small instead of "This workspace changed". A project that cannot be found is named in quotes: "“New project” can’t be found".
