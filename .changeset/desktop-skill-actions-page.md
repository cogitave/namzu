The Customize page can now add and remove things. On Skills, Add holds Upload skill (choose, drop or pick a folder, read what each skill would do and what it can run, then add them) and Create a skill; a skill of your own or the project's has Remove in its menu, which keeps a copy in the backups. On Connectors, Add custom connector opens a dialog for a name, an https address and an optional header written as an environment reference. A notice raised on the Customize page now shows over it instead of being hidden.
