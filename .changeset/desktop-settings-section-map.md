Settings rows now sit where their effect is. A new Desktop app section holds Use hardware acceleration (it was under General). Terminal now has three headings: Terminal tabs (Default terminal shell, which says it is Windows only, and Restore terminal tabs, both moved out of General), Terminal app, and Command line (output format and quiet output, now worded as settings for one-shot commands). Updates ends with a Command line group for the update channel and the two update checks, Tools holds the browser switch and code analysis, and Hypermode moved to Agent. Nothing saved changes: every key and value is the same, and an old remembered section still opens.

Engine rows read in plain words and sit under sub-headings (Choosing models, Limits, Memory, Terminal app: look, and so on). Under a row there is no "Default: X." line and no apply line: a choice marks its default (*Default · X*), a number or text box shows it as the placeholder, and a row that waits for a restart carries an *After restart* badge that spells the sentence out on hover and to a screen reader. Models, Agent, Tools and Projects say once, under the title, that most changes apply to new conversations.

The app's own rows read the same way: Permission requests and questions, Response errors, Finished long responses, Notification sound, Restore terminal tabs, Auto-dismiss popups, Virtualize conversations, Light and Dark code theme, Quick Entry keyboard shortcut, Providers and API keys, Read replies aloud and Microphone access. Each old name still finds its row in search. Sub-headings (Notifications, Providers, Code, Accessibility, Namzu Desktop, Tool servers and hooks, Your projects) and default marks inside choices were added, and the Quick Entry box now follows the app's light or dark look and font. Nothing saved changes.

Notifications has its own section after Appearance, under one heading, On this computer. Permission requests and Questions are each Off, Badge only (the count on the icon) or Banner (a system notification), Task complete is Off or Banner with a Long response time in seconds (30 unless you change it; a shorter response never notifies), Response errors is Off or Banner, and Notification sound is System sound or None. Your old notification switches carry over: on becomes Banner and off becomes Off, except that a permission or question banner you had switched off keeps its icon count as Badge only. Nothing changes for a file saved before these rows.

Tools has a Built-in browser group after the engine's Browser rows. Auto-open files Namzu writes (on) decides whether a page or picture Namzu writes opens in the Browser pane by itself; pictures now open there too. Keep cookies (Until you quit, Across restarts, Per conversation) sets how long a sign-in in the Browser pane lasts, and a change reaches new tabs only. Open links in built-in browser (on) opens a link in a reply in the pane instead of your default browser; turn it off to keep links going to the system browser. Connected browsers shows the Browser pane and the Browser Namzu uses, with Recheck. The pane's sign-ins were already forgotten when the app closed and are still, unless you choose Across restarts, and Per conversation, one set for each conversation, stays the default; Until you quit is one set shared by every conversation.
