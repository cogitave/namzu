Three more Settings rows are plain controls. Extra folders (Projects) lists each folder with Remove, adds one through the system folder picker, marks a folder that does not exist, and asks only when a folder is added. Turned-off skills (Agent) lists every installed skill with a switch, and keeps a name in your file that no skill has, with a note and Remove. Tool servers (Tools) can now add, change and remove the servers in your own settings: a name, then a program with arguments or a web address; adding or changing a program asks first, and variables and headers stay in the file, untouched and never shown.
