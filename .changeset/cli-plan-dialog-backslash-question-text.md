The plan approval box fits the screen: at 40 rows its question and answers no longer overlap, and a long plan pages inside the room left. Enter right after a single trailing backslash now starts a new line (the backslash is dropped) instead of sending the message; a doubled backslash still sends. While Ctrl+R's history search is open, typing and Backspace edit what is searched for instead of closing it. A question's focused option shows its whole description, and the question list no longer shows a `1/4` count that read like a question number. The accept-edits mode has one name, "Accept edits", in the footer, `/permissions`, Settings (the old words still find it in search) and the plan box ("Yes, and auto-accept edits"). A terminal that answers the keyboard-support query within a few milliseconds no longer prints `^[[?0u` on the folder-trust screen.
