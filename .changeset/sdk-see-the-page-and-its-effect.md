The `browser` and `browser_act` tools carry the page's effect back to the model. A `browser_act` result starts with `Effect:` (the host's own counts, and `no visible change` when a click did nothing), followed by the lines that appeared or went inside the untrusted envelope. `browser` gains `snapshot` fields `view` (`full`, `interactive`, `reading`, `delta`), `query` and `role`, `wait_for` `stable`, and a read-only `value` action; the new types are `BrowserEffect`, `BrowserValue` and `BrowserSnapshotView`, with `BrowserResult.effect` and `.value`, `BROWSER_FIND_MAX_MATCHES` and `renderBrowserEffect`. A custom `BrowserHost` keeps working unchanged: it need not return an effect, and need only handle `value` if it lists it among its actions. `wait_for` with nothing to wait for is now refused with a message that names `stable` too. With the Playwright host a screenshot now masks only password and one-time-code fields, not every input, so other text typed into an input (an address, a card number) is visible to the model in a screenshot; keep such values out of a page the agent can screenshot, or use a custom host that masks them. `browser` `navigate`, `back`, `forward` and `reload` results now carry a snapshot when the host returns one, and the tool text says not to snapshot again straight after.
