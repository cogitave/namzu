Errors, tool rows, approvals and update messages in Desktop use plain words. A failed start or stop shows "Namzu couldn’t start" or "Namzu couldn’t close cleanly" with a sentence and the original under Details; a tool row says "Didn’t finish (code 2)" or "Namzu couldn’t use that tool"; an approval says "Waiting to read a web page" instead of "Waiting to web fetch"; the end of a turn says "Tests passed" or "Tests failed" (the command is in the tooltip); the context ring says "6% of this conversation’s memory used" and "Shortening the conversation…". Nothing to do on upgrade.
