`/branch [name]` creates a branch of the current conversation at this point: this screen continues in the copy (titled `name` when you give one) and the original stays unchanged in `/resume`. `/fork` does the same for now; it is reserved for copying the conversation into a new background session and will change to that meaning when background sessions arrive, so use `/branch` for an in-place copy.
