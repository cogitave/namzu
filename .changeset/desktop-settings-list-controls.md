Six Settings rows that were raw JSON boxes are now plain controls. Notifications (Terminal) is three event checks, off when none is ticked, and says what "Waiting for you" is. The workspaces key is a pick that offers only keys that work. Each composer trigger has its own Arm, Suggest or Off choice with its default marked. Tool-result screens are checks with a list of tools the repeat-the-request screen lets through, and ask before one is dropped. What to save from a conversation file is a check per event type (all by default, with a note when none is ticked), and hiding secrets is one switch that asks before it goes off. Saved values are unchanged.
