Namzu Desktop no longer keeps asking a Pal's computer that is not set up: it reads it once, shows one setup card (what it is, Get Docker Desktop, about 1.2 GB of disk) and asks again only when you come back to the window, start the computer or finish setup. Failed reads of the undo status, your message settings and the model list now say what is wrong in plain words, are tried once more when Namzu reconnects, and no longer repeat on a timer. Nothing to change on your side.
