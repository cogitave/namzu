Agent rail and delegated-work behaviour fixes. `ctrl+x ctrl+k` now stops background agents from the composer as well as the rail: the first press asks for a second within 3 seconds, the second stops them and says how many, and with none running it says so; it no longer stops agents the turn is waiting on (use `x` on the row for those). A reply the model finishes is shown at once instead of when the whole turn settles, so its last sentence no longer hides while background agents run. An agent that fails again with the same reason after a message reads "failed again" in its notice. Messaging a finished agent keeps its row in place with the time and spend it had. The "(↓ to manage)" hint appears only when every agent in a launch runs in the background, and shrinks to "↓ agents" on a narrow footer instead of disappearing. Rail rows drop the type column when every row is the same type and show what the agent is doing beside its clock while keeping its description. The composer stays visible, dim, while the rail has the keys, and key hints are lower-case ("enter to view · x to stop"). The agent explorer says "agent" and "saved record" instead of "child" and "saved evidence". Nothing to change in your configuration.
