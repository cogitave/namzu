Fixes where the newer terminal screens meet. A read, search or listing that fails now stays in its counted line (nothing red on the line itself) and Ctrl+O shows that call with its error; every `(ctrl+o to expand)` hint now leads to the part it hides. A second Esc counts only if no other key came between the two presses, and the clear-the-draft and open-rewind windows never count toward each other. A row already on screen follows a theme change, mark included; `/config theme [name]` is new, and `/config tips` and `/config motion` accept `list`. A rewind point is a prompt you sent, never a `!command` echo, a recap or a notice. An idle compaction or a rewind summary hides the footer's context meter until the next reply and `/context` sizes the conversation from its messages meanwhile; an idle compaction no longer runs while the detailed transcript is open. Removing the last key of a block from the settings file (for example `/config recap on`) removes the empty block too.
