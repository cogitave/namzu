The detailed transcript (Ctrl+O) now draws the model's thinking above the counted read or search line it led to, not under the answer that followed. A permission request that waited behind the detailed transcript starts its settle window again when the screen closes, so a stray key cannot approve a call you have not seen. Thinking is not saved with a conversation, so a resumed or forked one shows none.
