Customize, Plugins: **Add** offers Add marketplace, Upload plugin and Create with Namzu; once a marketplace is added, Yours and Discover show the installed plugins by marketplace or a card grid of what the marketplaces offer; adding a plugin shows what it adds and runs and asks for a yes to that digest; each plugin can be turned off or on, checked for updates, updated and removed. The desktop host's `namzu/plugins/list` now also lists the plugins installed for this folder or for the person that the plugin folders do not hold, so a plugin installed from a marketplace or an upload shows with no conversation open. Nothing changes for an app that does not call the new methods.
