When your config file is broken, every Settings page now says so once, with the file, the line and the column, and "Fix it and choose Try again." Tool servers and Hooks wait with "Shown once your settings can be read." instead of repeating the error, and the hooks list no longer adds a "Not loaded" row for the same read failure. Two row descriptions that started in lower case now start with a capital.
