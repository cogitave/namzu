The terminal's notices are quieter and say things in plain words. Nothing in the public API changes. System rows share one coloured dot; compaction shows "Compacting conversation…" while it runs and then "Conversation compacted (ctrl+o for history)", with the summary behind Ctrl+O. Tool-result clearing no longer draws a row. "/compact" keeps whole turns and now counts in "/context". Interruptions read "Interrupted · What should Namzu do instead?". A pause always reads "Paused. … Press Enter to continue, or Esc to stop." Agents, workflows and background jobs end with "finished", "failed" or "stopped". Scripts that match the old English notice text (for example "context compacted", "Provider chain:", "Goal round") need updating; headless and "exec" output changes too: an automatic compaction now prints "Conversation compacted" without the message and token counts, the compaction-failure text is reworded, and a few notices say "reply" where they said "turn". "--json" output is unchanged. Automatic compaction in the middle of a reply now shows "Compacting conversation…" from the moment it starts.
