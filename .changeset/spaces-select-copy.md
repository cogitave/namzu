Spaces: drag to select text in a pane and it is copied when you let go (double-click picks a word, triple-click a line). New settings `tui.mouse` (`full`, `scroll` or `off`) and `tui.copyOnSelect`, and the environment variables `NAMZU_DISABLE_MOUSE` and `NAMZU_DISABLE_MOUSE_CLICKS`, let you capture less of the mouse or keep your terminal's own selection. Nothing breaks and no default changes for a plain `namzu` conversation, which never captures the mouse. `/copy` and a pane's own copy request now reach your terminal from inside spaces, and `/copy` works under tmux and screen. The mouse is switched off on `SIGTERM`, `SIGHUP` and `SIGINT`, and every interactive launch clears a mouse a killed run left on; no action needed. Copying now tries your machine's clipboard tool first (`pbcopy` on macOS, PowerShell `Set-Clipboard` on Windows and WSL with the text as UTF-8, `wl-copy`/`xclip`/`xsel` on Linux; not over SSH) and then the terminal's request, which is skipped only when a Linux tool worked in a VTE terminal; inside tmux the text also goes to tmux's paste buffer. This applies to the spaces selection, `/copy` and `/export` to the clipboard, runs in the background, and its notice reads "Copied N characters to the clipboard." when a tool took the text; nothing to do, and on WSL install nothing more, since `powershell.exe` is already there.
