A question now gets an answer instead of a string of commands. The default coding-agent prompt tells the model to answer or assess a question first, to open with the answer rather than an apology or agreement, to do in a step what that step says it will do, to reply in the person's language and in the form they asked for (money, not tokens), and says a reply that is itself the answer needs no line beside it. In the turn loop, a repeat of an earlier call with the same input and the same result no longer counts as a change, a repeated file edit still counts as a change, a turn whose latest message is a short question (a question mark that ends a sentence, at most 400 characters; a web address with a query string or a long brief does not qualify) is nudged to answer after 6 steps without a change (only steps that merely looked count toward it: a shell command counts as looking only when the shell policy calls it read-only; the general threshold stays 12; `reasoning.stall.answerAfterSteps` tunes it) and is never forced to call a tool, and the stall, reasoning-cap and repeat-call notices offer an answer with what the model has instead of "run one more command". A host that has its own copy of these texts keeps its own; nothing is removed or renamed.
