The Enter key on the number pad now sends a message, and the other number-pad keys work like the keys they match: the digits and `. / * - + = ,` type, and the pad's arrows, Home, End, Page Up, Page Down, Insert and Delete move and edit (Shift+pad Enter adds a line, as Shift+Enter does). On macOS, a file copied in Finder now pastes as an image with Ctrl+V, and pasting a screenshot's temporary preview path, whose file is already gone, attaches the screenshot from the clipboard instead of leaving the path in the message.
