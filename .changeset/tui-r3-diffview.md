Changes to files are drawn the way the reference terminal draws them. An edit's call row now reads `Update(path)` (it read `Edit(path)`); its result says `Added 2 lines, removed 1 line` with the numbers in bold, and the hunks sit under it with a line-number gutter, full-width green and red rows, the changed words highlighted when little of a changed pair differs, a dim `...` between hunks and no vertical rule. An edit shows every hunk the kernel carried (it used to stop after 40 rows); a created file reads `Wrote 14 lines to notes.txt` with its first 10 lines. A declined edit or write keeps `You declined this, so it did not run.` and shows what it would have changed in dimmed colours. Terminals that report truecolor get the reference's colours, others the named ANSI ones. `/diff` and resumed conversations draw the same rows; a resumed conversation without a journal keeps the line counts from the receipt. Anything that matched the old `Edit(...)` call text or the `Edited a.ts +2 -1` / `Created n.txt +2` result text in the terminal transcript should match the new wording; the structured events and the Desktop are unchanged. Adds `diff` 9.0.0 as a dependency.
