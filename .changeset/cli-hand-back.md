The model can now be allowed to hand a task back to a person instead of forcing a result it cannot honestly reach. Off by default; turn it on with `handBack.enabled: true` in your config, or `--hand-back` on `namzu exec`. When the model hands a task back, the terminal says so in Namzu's words and shows the model's own sentences under labels (what blocks it, what it tried, what a person has to decide or provide), a reopened conversation shows the same, `namzu exec` exits with the new status **3** (distinct from 0, done, and 1, failed; stderr says why and `--output-format json` carries an optional `handedBack` key, also on the `done` line of `exec --json`, which still exits 0), a goal round ends the goal as not confirmed, and a scheduled run ends with the new status `needs-a-person` and is counted, notified once and paused on repeats like a failing run. If you read scheduled run statuses, handle `needs-a-person`; it only appears when you turn the setting on. Nothing changes unless you do: with it off the tool is absent and the prompt is unchanged. Before it could become the default it needs a measurement with real models on tasks that cannot be done as specified, against how often a model hands back a task it could have finished.
