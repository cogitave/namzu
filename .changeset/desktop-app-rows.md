Settings gets switches the system applies, and nothing changes until you use them, except one: the system tray is on by default, so closing the last window now leaves Namzu running with an icon beside the clock (choose Quit from it, or turn *System tray* off under Desktop app to quit on close as before). New: *Run on startup* (Windows and macOS), *Keep computer awake*, *Keep computer awake while working* with *Keep awake on battery power* (under Agent), and *Pause downloads on low data* (Windows; app and engine downloads that start by themselves wait while the connection is metered). A change the system refuses is said in one line under the row. Old settings files load with the defaults. New under Desktop app: *Quick Entry shortcut* (Ctrl+Alt+Space by default; press it anywhere, type a line, press Enter to start a conversation), *Dictation shortcut* (Ctrl+D by default, in the message box) and *Voice shortcut* (off until you set it). A shortcut another app already holds is not registered and the row says so. If Ctrl+D in the message box matters to you, set the Dictation shortcut to Off.
