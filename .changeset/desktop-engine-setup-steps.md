Setting up Codex or Claude Code from the model popup no longer ends in a dead end. An engine that is not installed shows **How to install** with the exact command for your system, a Copy button and **Check again** (also in Settings ▸ Updates); an engine that is installed but signed out says to sign in first, shows the command to run, and has an **Open terminal** button; the model button says "Not available" instead of staying a grey bar. The popup keeps one width across its steps, the effort slider shows its level names, one line explains Desktop | CLI, and the "Choose a model" heading is no longer covered by the engine mark.
