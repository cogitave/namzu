Terminal: a dialog or picker no longer shows a half footer under it (the model name alone, or the mode without its cycle hint); the footer is drawn only with the message box. A workflow whose agent failed now says `1 failed` beside the count on the rail and in the workflow view. A workflow script that could not run is one plain sentence in the conversation, with the line it stopped on behind ctrl+o. A `+500k` token target is read only from what you typed, so a note Namzu adds on its own (a finished job, peer mail, a goal round) can no longer set one.
