The message box has three menus. Typing "/" lists the commands this window runs (model, plan, permissions, side chat, fork, the panes, Settings pages and more), each with a short note beside the highlighted row; choosing one never starts a reply, and a command that takes text leaves "/name " with a grey hint. The "+" button opens a menu with Add files or photos (Ctrl+U, Cmd+U on a Mac), Slash commands, Tool servers and Plugins, and Esc now closes it in one press per level. Typing "@" lists the project's files and writes `@path ` where you chose. The empty box reads "Type / for commands" in an open conversation. A message that starts with "/" and is not one of these commands is sent as before.
