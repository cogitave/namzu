Adds the monitor and the presence overlay of the native Windows helper (`namzu-win`). `NativeForegroundMonitor` lets the foreground ladder see a person taking over, and `NativePresence` draws the agent's cursor and window frame, both through the helper instead of PowerShell. The monitor learns of keyboard and mouse use from Raw Input headers (which kind of device, and when), never which key, and follows the window in front with a window event hook; it installs no system-wide keyboard or mouse hook, which is the thing the PowerShell monitor did that antivirus products flag. The native overlay is not hidden from screen capture, so a screenshot of the display may show where the agent pointed; the PowerShell overlay excluded itself from capture. One difference for a caller of the monitor: it cannot tell Escape from another key, so `escapes` is always 0 and a person stops a burst by using the machine. `createWindowsForegroundLadder` and `createWindowsPresence` take a new optional `helper` and use it when `NAMZU_WIN_HELPER` names one; with neither set nothing changes, nothing delivers the helper yet, and nothing needs doing on upgrade.
