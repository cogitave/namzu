'@namzu/cli': minor

An agent can now be waited on, messaged, resumed or cancelled by its task id from any later turn of the same conversation, whether it is still running or has already ended. Before, an agent whose turn had ended could be reached only while it was running, and every other id was refused with "does not belong to this parent turn", so a task id taken from an earlier notification often failed. A finished agent returns its result without a new wait, `cancel_agent` reports that it already ended, and `send_message` resumes it from its own transcript under the current turn's limits and review channel; an agent you stopped is still not resumed. An id that belongs to no agent of the conversation, or to another conversation, now answers "No task with ID … in this conversation." and lists the agents that are running. If you call the sub-agent tools from the SDK, match on that text instead of the old one. A message to a running agent now also reaches it after the turn that launched it has ended, and a message to an agent saved by an earlier run of the program (its session UUID from `agent_task_list` with `history: true`) resumes it from its saved history under the current turn's limits and review channel, or says it cannot be resumed when nothing readable was kept. Requires `@namzu/sdk` with `restoreChild`.

An agent started with a role is the exception: its role text is not saved, so after a restart it cannot be continued and a message to it says so. A resumed agent's duration keeps counting from its original start while it is still tracked, and from the restore when it is not.

An agent also keeps one task id across resumes: the notification, `agent_task_list`, `wait_for_task` and `send_message` show the id it was first known by, and that id keeps working. A restored agent keeps the short name it was launched with instead of its prompt, a finished agent no longer reads as `unresolved` when its own log settled, a saved model that names no provider is ignored, and two messages that meet an agent being resumed are told in plain words to wait for its notification.
