Settings > Appearance gets more choices, and nothing changes until you use them. The theme is a three-part control (System, Light, Dark). The interface font can be one installed on this computer (press Find installed fonts). New rows: a response font for replies only, the transcript's text size (small, medium, large) and width (narrow is the width you have now, medium, wide), Motion (System, Reduce, Full), whether notices close by themselves, and whether parts of a long conversation that are off screen are left undrawn. Old settings files load with today's values.
