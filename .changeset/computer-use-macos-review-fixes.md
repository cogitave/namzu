The macOS names of browsers and editors (`Google Chrome`, `Microsoft Edge`, `Sublime Text`, `Android Studio` and the like) now get the same view-only and no-typing limits as their Windows and Linux process names; before, computer use treated them as ordinary applications. A Mac with swiftc only as the empty shim now gets the `xcode-select --install` instruction instead of a compile error.
