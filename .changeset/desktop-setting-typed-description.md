Settings rows now show their real default and a line saying when a change applies (at once, to new conversations, the next time Namzu starts, or the next time the app opens). Switches that are on by default show On while unset, choice lists use plain words with one line of help for the chosen option, and Locate on a project says it asks you to trust the new folder. Search also finds rows by other apps' words: "chat font", "ui font", "text size", "startup", "tray". The graphics card, engine and engine-update rows are now found by search too.
