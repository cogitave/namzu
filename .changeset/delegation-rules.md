The coding-agent delegation guidance, the `Agent` tool description and the explore prompt are rewritten: do small or known-target work inline, delegate independent, large or context-flooding work, never redo delegated work, pass paths and what is ruled out rather than a conclusion, treat a child's report as a claim and check one claim, keep parallel writers apart, and use explore to locate small answers. The rules appear only when delegation is mounted; hypermode is unchanged. A host that pins the old doctrine text in a test will see the new wording. Nothing to change otherwise.
