The conversation screen's message box is quieter. The box now holds only your text, the "+" for attachments and the send button (Stop and the queue button appear there while a reply runs), with rounder 16 px corners. The settings of the conversation moved to one small row under the box: the project and where it runs (home screen only), the permission mode ("Ask first" and the others, same menu), the model (it stays there, greyed out, while an approval waits) and the context percentage. The context percentage used to sit in the top bar; it now sits at the right end of that row, with the same popup and the same numbers. A narrow window drops the percentage first, then shortens the model's name, then wraps the row to two lines; the permission mode is never cut. An approval is now one card directly above the box instead of a box inside a box, with the preview of the change running edge to edge. On the home screen the project line fades out on your first message and the permission mode slides into place. Nothing you could do is gone: every control is still there, with the same words, menus and keys, and every one is drawn at rest, so the keyboard and touch reach it without hovering.
