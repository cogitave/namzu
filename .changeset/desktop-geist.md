Namzu Desktop now draws with its own typefaces: Geist for text and Geist Mono for code, the same on every operating system, instead of whatever sans and monospace the machine happens to have. Letters are a little wider and rounder than the system's, code is no longer drawn in a typewriter-like face on machines that lacked a good monospace, and the numbers that change while you watch (times, counts, percentages, a table's cells) now hold their width exactly. Emphasis in a reply uses a true italic; italic code is the upright mono slanted. To keep your platform's fonts, open Settings, Appearance, and set Interface font to "Your device's": it takes effect at once, with no restart, for text and code. The terminal keeps Geist Mono either way. Nothing else changed and no setting moved. Geist is under the SIL Open Font License; its notice is in the app's third-party notices.
