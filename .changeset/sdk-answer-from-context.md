The model is no longer sent to search its own conversation for what it can already see. One rule is told wherever history comes up: answer from your own visible messages and tool results, and use the history tools only for something no longer visible. Pointers to those tools (`additionalEvidence`, `continuations`, the tool names) are shown only once a compaction summary or a cleared tool result is in the conversation. A recalled assistant message is framed as what the model itself said, to be quoted for a "why did you say" question, and only a question about the current state of the world is re-checked; the working doctrine says the same. The history planner now uses a mostly usable plan instead of refusing it (over-long lists are cut, a quote the history does not hold is ignored, a reply in a code fence or with a repeated key is read), reads the start and end of a long reply, is skipped when the question points at the model's own whole last reply, and a lookup that found passages is no longer announced as "not available". New optional `EvidenceRecallOptions.log` receives one line with the reason a lookup stage did not run. Nothing a caller does has to change.
