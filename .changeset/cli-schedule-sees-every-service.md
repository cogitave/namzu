'@namzu/cli': major
---

`namzu schedule list` and the TUI's `/schedule` now show the jobs of every installed scheduler service, each under the service's name after the current home's jobs, and `namzu schedule <show|history|pause|resume|run|remove|edit|confirm> <job>` finds the job by name in the current home and in every service (one match acts on it and says which service; a name found in several homes is refused with the `--service <name>` form). `/schedule confirm|pause|resume|run|remove <job>` act on the service's home too, and a confirmation still needs a person. `schedule list --json` gains a `services` array when services are installed; nothing changes when none is. Pass `--service <name>` or `--home <dir>` to keep acting on one home.

**Breaking: a named scheduler service now lives in the Namzu folder, and `--name` is gone.** `namzu schedule service install --name <n>` no longer runs: it prints one line and exits 64. Write `namzu schedule service install <n>` instead; the service's home is then `~/.namzu/services/<n>` (created if missing), where it used to be whatever `NAMZU_HOME` or `--home` pointed at. `namzu schedule service install` with no name is unchanged (the current home's own scheduler), and `--home <dir>` still picks a folder yourself. A script or unit that passed `--name` must be changed; a service you already installed keeps working where it is, and `namzu schedule service move <n> [--dry-run]` brings it into `~/.namzu/services/<n>` (refused while a run is in progress, never copy-then-delete). A job's confirmation survives the move when its folder is a project folder; a no-project job's scratch folder is part of the move, so that job must be confirmed again with `namzu schedule confirm <job> --service <n>`.

**A job folder may no longer be inside or contain the default Namzu home or any installed service's home** (before, only the job's own home). A job that was confirmed in such a folder is refused when it next runs; edit it to use a project folder. `namzu state purge` never reaches `services/`.
