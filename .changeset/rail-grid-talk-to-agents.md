The agents rail, the workflow detail and talking to a sub-agent now follow the reference terminal. What changes for you:

- The rail has a blank row above it, its bullet sits under the footer line's first glyph, rows stop two cells short of the edge, and the pointer and bullets use no accent colour. While the rail has the keys its key line (`Enter to view · x to stop`, plus `ctrl+x ctrl+k to stop all agents` when several run) replaces the footer's mode line instead of being printed under the rows. A background agent that completes leaves the rail at once; a failed or stopped one stays 30 seconds. `ctrl+x ctrl+k` on the rail stops every running agent.
- A running background agent's description column becomes a live three-to-five-word label, refreshed at most every 30 seconds by one tool-less request to the agent's own model; it adds model usage, and falls back to the launch description. A message waiting for an agent shows as `N queued`.
- The workflow detail is a frameless dialog, side by side from 64 columns.
- Enter on an agent now views it on the main screen with the one composer live (`Message @<type>…`): typing sends to the agent, Esc or the `main` row goes back, and the separate message box is gone. A finished agent is resumed by a message; `send_message` does the same, and refuses an agent you stopped.
- Finished agents that run on their own (background, a wait that was released, or resumed by a message) leave `› Message from @<type> (ctrl+o to expand)` (collapsed) and `● Agent "<description>" finished · 1m 4s` in the conversation instead of the old `✓ name · time · tokens` row; a stop reads `was stopped by user`, `was stopped by Namzu` (the conversation's own `cancel_agent`) or `was stopped`, a failure `failed: <reason>` (`Unknown error` when none). An agent the parent waited on leaves `● <type> (<description>)` over `⎿ Done (3 tool uses · 12.1k tokens · 8s)` and no notification. The launch receipt lists each agent by its description. Scripts that read the old rows must follow the new wording.
- While you view an agent, Esc stops it if it is running (and stays in the view) and goes back once it has ended; Ctrl+C stops it and goes back. Slash commands typed there are no longer sent to the agent when Namzu answers them itself: `/model` is refused, `/compact`, `/clear` and `/new` ask first, other built-ins run on the conversation; text after `/` that is not a built-in still goes to the agent.
- A running agent can message the conversation with its own `send_message` (`to: "main"`); you see `› Message from @<type> (ctrl+o to expand)` and the model reads the text, framed as the agent's own words, with its next turn. An agent's token figure on the rail points up (`↑`) until its first tool call. The live label's request is counted on the turn's token ledger (small, at most 8,000 tokens from a limited turn) and is written in the predominant language of the agent's notes. A workflow detail list longer than its box says which rows show on the box's bottom border (`↑ 3–16 of 16`).
- The `Agent` tool's `description` parameter now asks for a short (3-5 word) description of the task.
