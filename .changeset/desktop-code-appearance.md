Settings > Appearance gets choices for code, and nothing changes until you use them. Pick the colours of code in diffs and file views for the light and the dark window (Default, Soft, Vivid, High contrast, Warm), with a sample under each row. Set a code font (any monospace font installed on this computer) and a code size from 11 to 18 px; the terminal uses them too, and open terminals take them at once. Terminal settings link to these rows. Old settings files load with today's values.
