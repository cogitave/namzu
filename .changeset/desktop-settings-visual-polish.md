Settings and a few screens read more plainly. Updates found together share one notice instead of stacking; Update from Settings keeps you in Settings with progress on the row and a link to the terminal output; the Updates page no longer offers an automatic-download switch where the app cannot update itself; a separately installed Namzu command line is labelled as such. The "waiting to restart" dialog says what it waits for. Speech before the download is one Download voice button, and About shows versions and your system in plain words with a Copy details button; raw folder paths appear only under Data folders. Settings search finds Turkish capitals (İ, ı), each page has one heading, and the terminal shell row appears only where there is a choice. On a narrow window the Changes panel takes the whole pane instead of squeezing the chat, the project chips sit flat on the composer's edges, and times follow your system's clock style everywhere.
