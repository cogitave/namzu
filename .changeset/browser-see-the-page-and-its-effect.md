'@namzu/browser': minor
---

The browser host now shows the model what it needs to act with confidence. A native `<select>` shows its chosen option and its options (they were dropped before, so a model could not confirm a selection), a text field says what it holds or `[empty]`, and each page-changing action returns an `effect` computed from the page before and after: the address change, the lines that appeared or went, or no visible change. The fixed 150 ms wait after an action is replaced by a wait for a quiet page (no change to the document and no request in flight for 250 ms, capped at 2 s after an action and 5 s after a navigation, with the cap reported). `snapshot` can return only what changed (`view: "delta"`), only what can be acted on (`"interactive"`), or the page text (`"reading"`), and can find elements by `query` and `role`; `wait_for` takes `stable`; a new `value` action reads one control. Screenshots now mask only password and one-time-code fields instead of every input. Nothing is removed. A caller that compared the exact text of a textbox line now sees `[empty]` on empty fields. `navigate`, `back`, `forward` and `reload` now return the page's snapshot as well as its header when the page has something to read (the result still carries `page`), so a caller that read only the header still works.
