Pressing the context ring opens a panel that shows where the conversation's memory goes: how much is used and what of, a thin bar in colours, one row each for messages, built-in tools, tool server tools, Namzu's instructions, skills and project notes, the tools that are only loaded when needed, the room kept free, and the tool servers folded with their tool counts. A line says whether the total is exact or Namzu's own estimate. It refreshes while it is open, in light and dark.
