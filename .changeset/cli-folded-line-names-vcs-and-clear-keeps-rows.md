The counted line that folds a run of successful shell commands now says what the version-control ones did: `Made 1 commit, pushed 1 time, opened 1 pull request, ran 2 commands` instead of `ran 5 commands`. Commits (amended ones as such), pushes, branches created or switched to, merges, rebases and pull requests opened or merged with `gh` are counted, in that order, before the plain count; reads such as `git status` or `git log`, a dry run, an alias, a command inside quotes and anything joined with `;`, `||` or a pipe stay in `ran N commands`. The commands listed under the line and the detail behind Ctrl+O are unchanged. There is no setting for this; if you want the old wording the list under the line still names every command. On the default screen, `/clear` and Ctrl+L no longer lose the last finished rows of a reply that had not been printed into the scrollback yet: they are printed first, then the screen is cleared, so everything that was visible is in the scrollback once and in order (a screen reader, no-colour, the old painting with `NAMZU_LEGACY_PAINT=1`, the zoomed workspaces screen and the fullscreen view are unchanged). The input box after a turn is unchanged.
