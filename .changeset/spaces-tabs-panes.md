"@namzu/cli": minor

`namzu spaces` now shows each space as tabs of tiled panes: a tab bar across the top of the workspace area, and under it a split tree of bordered panes, each pane its own Namzu session sized to its inside (the focused pane's border is light blue, the others dim grey; the borders fall back to the nearest 16 colours unless `COLORTERM` is `truecolor` or `24bit`). The keys are now one command after the prefix instead of a sticky navigate mode: `ctrl+b` then `v` or `-` splits, `h j k l` moves focus, `H J K L` swaps, `z` zooms, `r` enters resize mode (`l`/`j` move the nearest border right/down, `h`/`k` left/up), `x` closes the pane, `c` opens a tab and asks for its name, `n`/`p`/`1`-`9` switch tabs, `T` and `X` rename and close one, `N` `W` `D` create, rename and close a space, `w` moves between spaces, `b` hides the sidebar and `q` quits; `ctrl+b ctrl+b` still sends a literal `ctrl+b`. The earlier preview's keys (`n` new session, `j`/`k` between sessions, `r`/`R`/`d`/`D`, number keys for spaces) are gone. You can also click a pane, a tab or "+", drag a border to resize, and scroll the pane under the pointer. `spaces.json` is rewritten as version 2 with each tab's pane tree; an earlier file is read as one tab per session in the same order. Nothing changes for plain `namzu`. The sidebar is now two sections: spaces (a state dot and bold name over the git branch with ahead/behind arrows, "new" and "menu" at the foot) and agents (every session of every space, two lines each, grouped or by priority, click to focus). `b` collapses it to a rail of index-and-dot rows, its edge drags to resize, and the bottom mode bar shows only the keys that work in the active mode. `N` now opens a space in the focused pane's folder without asking; `O` asks for a folder. A finished-not-seen dot is teal instead of blue. Naming and confirming now happen in centred modals over a dimmed screen (`N` asks for the folder with the focused pane's filled in, renames start with the current name, closing a space asks with a confirm button, the account picker is a modal list), right-click opens a context menu on a space, tab or pane, spaces drag to reorder, `ctrl+b` then `g` opens a filterable go-to tree and `?` a keybinds overlay printed from the key map the host runs, `s` or "menu" opens a menu of accounts, add account, sidebar, keybinds and quit, every overlay closes on `esc` or a click outside, and clicks no longer pass through an open prompt.
