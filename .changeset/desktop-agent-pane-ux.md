When the agent works in a tab of the Browser pane, you can now see and steer it: the tab is marked "Namzu is using this tab" with a dot that shows when a call is on the page, the pane shows itself the first time (without taking the focus from the message box), and Take over and Hand back pause and resume the agent. A sign-in that Namzu needs from you in the pane says "Sign in to <site> in the Browser pane", with a quiet Show the tab action at the left, Stop and Continue together at the right on one row, and no terminal command. Nothing changes until the engine uses the pane.

While you hold a tab Namzu was using (to sign in, say), Namzu is told only where the page is, never what you type or submit, and taking over stops what it had running there. Site rules a conversation's first open set can only get tighter while the same engine holds the tab. A narrow window no longer covers the conversation with the pane for a sign-in pause; Show the tab opens it. Keep cookies now says that pages Namzu opens share sign-ins across conversations unless it is set to per conversation.
