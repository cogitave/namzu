`runExperiment` can now say how sure its report is. New optional `repeats` (1 to 100) runs every case several times; the report keeps each run (marked with `repeat`) and adds `caseSummaries` and `reliability` (the fraction of cases that passed every repeat). New optional `seed` drives a bootstrap over cases that puts a 95% interval on the mean score and the pass rate, in `intervals`, for the suite and for each split; with fewer than 5 cases the interval is not computed and says why. A case may declare `split: 'development' | 'held-out'`. A suite may pass `disclosure` (scripted or real model, provider and model per role, routing, reasoning effort); the report records it with the harness and SDK versions, the date, the case and repeat counts and the seed, and writes `unknown` for anything not stated. `formatReport` prints the intervals next to the numbers. New exports: `compareEvalReports`, `formatEvalComparison` and `loadEvalReportFile` (a paired comparison of two report files with a paired bootstrap, an exact sign test on the flips and a disclosure diff), `summarizeRun`, `formatRunSummary`, `withEvalRunOptions`, `bootstrapCases`, `bootstrapPairedDifference`, `exactSignTestP`. With no repeats the report has the same fields as before plus the new optional ones. One change to printed text: `formatReport` shows the bootstrap interval in place of the earlier "±" line (the `uncertainty` field is still filled). Nothing to change on your side.
