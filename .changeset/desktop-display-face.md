The home screen's heading now draws the project's name in a pixel typeface (Geist Pixel, shape Square), a little lighter and squarer than the rest of the sentence, which stays in Geist. A project folder can be named with any characters: the name is drawn in pixel letters only when the face has every character of it (Latin letters, Turkish letters such as ç ğ ı İ ş ö ü, digits and common punctuation); a name with a Cyrillic, CJK or emoji character, or any other character the face lacks, stays whole in Geist, never a mix inside one name. The heading keeps its height and its baseline. Settings, Appearance, Interface font set to "Your device's" turns the pixel letters off with the other shipped faces, at once, with no restart. Nothing else is drawn in the pixel face, and no setting moved. Geist Pixel is under the SIL Open Font License; its copyright notice is in the app's third-party notices.
