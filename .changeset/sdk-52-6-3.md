Version 52.6.2 was never published to npm: the registry reserved that version number for a staged publish that it then dropped, and it refuses to publish 52.6.2 again. 52.6.3 is that release. If you pinned `52.6.2`, pin `52.6.3`; nothing else changes. It carries the same change as the 52.6.2 entry below: the published file list is identical (the same 4321 files, every `exports` target present), selected by extension instead of by globs, so `pnpm pack` and `pnpm publish` of this package take about 4 seconds instead of about 90.
