New `namzu config list|get|set|unset` command, and `/config <setting> [value]` in the terminal app, to read and change any setting Desktop Settings shows. Both read the engine's setting description, so a value Desktop refuses is refused with the same sentence and a risky change asks the same question (without a terminal it is refused unless `--yes` is given). Nothing existing changes: the `/config` subcommands keep their meaning and only the user config file is written.
